# Quarterly incident-remediation program

Six postmortems need to become one funded remediation program for the coming
quarter. The decision must reflect both recurring incident evidence and the
engineering cost and testability of candidate controls.

Postmortem synthesis, control feasibility, and organizational delivery planning
may proceed in parallel. The final plan must connect source incidents to owners,
dependencies, team capacity, change windows, measurable success signals, and
one first funded initiative. Only one program can receive the first quarterly
slot.

The service owner will not be available after the opening brief. Preserve any
owner-controlled priority, choose a reversible planning default, and finish the
package without claiming budget approval that is not documented.
