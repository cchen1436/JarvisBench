# Workspace applications

Use `jb collections` to see available collections, `jb list <collection>` or
`jb search "<terms>"` to inspect records, and `jb get <collection> <id>` for a
single record. Use `jb act <action> --json '<object>'` for validated mock side
effects. `jb status` lists the allowed actions.

All actions are local benchmark mocks. They are logged for audit. Save the
requested final artifacts under `results/`.
